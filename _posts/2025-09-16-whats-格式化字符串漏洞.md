格式化函数（如 **C** 语言的 `printf`、**Python** 的 `str.format` 或 `f-string`）会根据 **格式化占位符** 来访问内存或变量。

格式化字符串漏洞是 **程序直接使用用户输入作为格式化字符串**，而没有对输入进行过滤，导致攻击者可以控制格式化操作，在格式化字符串里插入访问或修改内存的指令，从而泄露信息或执行任意代码。

## In Python

在 **python** 中，提供了 **4种** 主要的格式化字符串方式，分别如下：
### 1.%操作符
```
>>> name = 'Bob'
>>> 'Hello, %s' % name
"Hello, Bob"
```
### 2.string.Template
使用标准库中的模板字符串类进行字符串格式化。
```
>>> name = 'Bob'
>>> from string import Template
>>> t = Template('Hey, $name!')
>>> t.substitute(name=name)
'Hey, Bob!'
```
### 3.format()
`python3`后引入的新版格式化字符串写法，但是这种写法存在安全隐患。
```
>>> config = {'SECRET_KEY': '12345'}
>>> class User(object):
...  def __init__(self, name):
...   self.name = name
...
>>> user = User('joe')
>>> '{0.__class__.__init__.__globals__[config]}'.format(user)
"{'SECRET_KEY': '12345'}"
```
`0`指向`user`，借助`user`的类拿到全局变量`config`，`format()`将其作字符串输出。
**0表示的是format()的第一个参数，同理，1表示第二个参数。**
